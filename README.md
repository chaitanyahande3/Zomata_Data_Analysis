# Zomato Data Analysis & Dashboard

## 📌 Project Overview

An end-to-end data analytics project based on Zomato restaurant
data, covering data preparation, SQL analysis, visualization and
business insights.

## 🛠️ Tools Used

- Excel
- MySQL
- Power BI
- Tableau

## 🔄 Project Workflow

Raw Data
   ↓
Excel Data Preparation
   ↓
MySQL Data Analysis
   ↓
Power BI Dashboard
   ↓
Tableau Dashboard
   ↓
Business Insights

## 📊 Key Analysis

- Restaurant distribution by country/city
- Restaurant ratings
- Cuisine analysis
- Price range analysis
- Online delivery availability
- Customer voting/review analysis
- Top-performing locations
